# Todo App

Manage tasks using this todo app. Break down larger tasks into smaller subtasks 
using checklists. Organize tasks into projects.

## Stack

HTML, CSS, JavaScript and Webpack.

## Local Development

1. Clone the repository using git clone with your preferred method (I use ssh):

`git clone git@github.com:saudshah207/todo.git`

2. Move into the project directory:

`cd todo`

3. Install dependencies:

`npm install`

4. Start the development server:

`npm run dev`

5. Access the app at the url shown in the terminal (typically http://localhost:8080/)
